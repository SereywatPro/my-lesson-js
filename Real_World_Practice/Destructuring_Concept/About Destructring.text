Destructuring in JavaScript
\1. Array Destructuring:
Array destructuring is a way to unpack values from arrays into distinct variables. This simplifies the process of accessing and assigning values from arrays.

Example

let arr = [1, 2, 3];
let [a, b, c] = arr;

console.log(a); // 1
console.log(b); // 2
console.log(c); // 3
Explanation: The variables a, b, and c get assigned the corresponding values from the array arr based on their position.

\2. Object Destructuring:
Object destructuring is similar but works with objects, allowing you to unpack properties into variables by their name.

Example

let person = { name: 'John', age: 30 };
let { name, age } = person;

console.log(name); // 'John'
console.log(age);  // 30
Explanation: The variables name and age are assigned the values of the corresponding properties from the object person.
Why Use Destructuring?
Cleaner and More Concise Code: Destructuring makes it easier to extract values from arrays and objects, reducing the need for repetitive code.

Improves Readability: It clarifies what values are being extracted without needing to access array indices or object keys explicitly.

Handles Default Values: You can set default values if an item is missing from an array or object, preventing errors.

let [a = 5, b = 10] = [1];
console.log(a); // 1
console.log(b); // 10

More Efficient Function Arguments: It simplifies passing multiple arguments to a function, especially when dealing with objects or arrays.

function displayInfo({ name, age }) {
  console.log(name, age);
}

displayInfo({ name: 'Alice', age: 25 });

\3.When to Use Destructuring?
When dealing with multiple elements in arrays or objects where you need to extract specific values.
In function parameters where an object or array is passed and you need to extract specific data from it.
When you want to assign default values if certain properties in an object or values in an array are missing.

Example with default values

let { name, country = 'USA' } = { name: 'Jane' };
console.log(country); // 'USA'

Destructuring can be particularly helpful in managing complex data structures efficiently and writing clean, readable code.
